# ルール:
#   - 1 行 = 1 質問 (5 エージェントが順に処理して 1 つの統合回答を返す)
#   - # で始まる行はコメント、空行は無視
#   - トピックは自由 (テック動向 / 業界調査 / 株・金融 / 日常の疑問 など何でも)
#
# ⚠️ コスト管理:
#   Gemini 無料枠は 2026/5 時点で gemini-2.5-flash が 1 日 20 リクエストのみ。
#   1 質問 = 5〜10 calls 消費 (差し戻し含む)。無料枠維持なら 2 質問が安全圏。
#   それ以上の運用は Tier 1 アップグレード (クレジットカード登録) を検討。
#
# 💡 ヒント:
#   - 株・金融ネタの場合は質問に銘柄名/ティッカー (NVDA, AAPL, トヨタ等) を含めると
#     yfinance で最新株価が自動注入されて精度が上がります。
#   - 「先週と比べて」「前回」などの語は ChromaDB の過去 Q&A 検索を活用します。
